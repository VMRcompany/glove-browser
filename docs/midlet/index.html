Glove Browser — Java-приложение для телефона

Это отдельная программа для установки на телефон. Не HTML и не ZIP: файлы GloveBrowser.jad + GloveBrowser.jar (MIDP 2.0 / CLDC 1.1).

Скачать GloveBrowser.jad Скачать GloveBrowser.jar

Размер JAR: 10215 байт · Версия MIDlet: 1.0.0 · Пакет: com.glove.browser.GloveMidlet

Для Samsung GT и Nokia: скачайте оба файла в одну папку (или откройте .jad — телефон подтянет .jar). APK эти модели не ставят. После установки программа появляется в меню приложений.
