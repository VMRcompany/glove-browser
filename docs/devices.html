Установка на Samsung GT и Nokia

Samsung GT и Nokia здесь — кнопочные Java-телефоны. Они не ставят APK. Нужны файлы установки Java-приложения: GloveBrowser.jad и GloveBrowser.jar. После установки программа появляется в меню приложений.

Скачать GloveBrowser.jad Скачать GloveBrowser.jar

MIDlet 1.0.0 · JAR 10215 байт · MIDP 2.0 / CLDC 1.1 · com.glove.browser.GloveMidlet
Один и тот же установщик для Samsung GT и Nokia.

Как установить (Samsung GT и Nokia одинаково)

С ПК по USB / карте памяти

  1. Скачайте оба файла в одну папку: GloveBrowser.jad и GloveBrowser.jar.
  2. Скопируйте их в память телефона (корень карты, Games, Applications или Installs).
  3. На телефоне откройте диспетчер файлов → GloveBrowser.jad → Открыть / Установить.
  4. Подтвердите установку Java-приложения. Телефон сверит размер JAR (10215 байт) с полем в JAD.
  5. Запустите Glove Browser из меню приложений — это отдельная программа, не страница в браузере.

По Bluetooth

  1. Отправьте на телефон оба файла: GloveBrowser.jad и GloveBrowser.jar.
  2. Во входящих откройте .jad и подтвердите установку.
  3. Если телефон просит JAR — укажите уже принятый GloveBrowser.jar рядом.

По ссылке с телефона

Откройте https://glove.mineholde.pro/midlet/GloveBrowser.jad — телефон предложит установить приложение и скачает JAR сам. APK для этих моделей не используется.
