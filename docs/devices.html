Установка на Samsung GT и Nokia

Glove Browser ставится как отдельное приложение (не открывается внутри Opera Mini и не раздаётся ZIP с HTML).

Samsung GT — APK (Legacy) Nokia — GloveBrowser.jad Nokia — GloveBrowser.jar

Android Legacy 1.8.7 · пакет com.glove.browser.legacy · Android 4.0+

Nokia (Series 40, Asha и Java MIDP) — как Opera Mini

Нужны два файла установки: GloveBrowser.jad и GloveBrowser.jar. После установки иконка появляется в меню приложений телефона.

С ПК по USB / карте памяти

  1. Скачайте на компьютер оба файла: GloveBrowser.jad и GloveBrowser.jar (в одну папку).
  2. Скопируйте оба файла в память телефона (корень карты, папка Games или Installs).
  3. На телефоне откройте диспетчер файлов → найдите GloveBrowser.jad → Открыть / Установить.
  4. Подтвердите установку Java-приложения. Телефон проверит размер JAR (10215 байт) по данным из JAD.
  5. Запустите Glove Browser из меню приложений — это отдельная программа, не браузерная страница.

По Bluetooth

  1. Отправьте на Nokia файлы GloveBrowser.jad и GloveBrowser.jar.
  2. В «Входящих» откройте .jad и подтвердите установку.
  3. Если телефон спрашивает JAR — укажите уже принятый GloveBrowser.jar рядом.

По ссылке с телефона

Откройте на телефоне https://glove.mineholde.pro/midlet/GloveBrowser.jad — система предложит установить приложение и скачает JAR с того же адреса.

Samsung GT на Android — файл APK

Для Samsung GT с Android (Galaxy и др.) ставится установочный APK, не JAR и не ZIP: GloveBrowser-Legacy.apk (версия 1.8.7, Android 4.0+).

  1. Скачайте GloveBrowser-Legacy.apk на телефон или скопируйте с ПК.
  2. Разрешите установку из неизвестных источников (Настройки → Безопасность).
  3. Откройте APK в «Мои файлы» и нажмите Установить.
  4. Запустите Glove Browser как обычное приложение из списка программ.

Кнопочные Samsung GT с Java (не Android), например часть линейки GT-C / GT-E / GT-S на платформе Java, ставят те же .jad/.jar, что и Nokia.
